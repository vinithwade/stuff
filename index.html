FAQ

Questions, answered.

Does Stuff replace Claude Code or Cursor?

No — it orchestrates them. Your agents stay the workers; Stuff is the planning, permission, verification and review layer above them.

Is it model-agnostic?

Yes. Stuff routes each task to the best agent — Claude, Codex, Cursor or Gemini — and tracks cost as it goes.

How does it keep my codebase safe?

Agents run in isolated branches and containers with scoped files, allowed commands and short-lived tokens. A policy engine gates anything risky, and every action is audited.

Can it run on-prem?

Yes. Enterprise private runners keep execution, credentials and code inside your environment while streaming traces to your control center.
